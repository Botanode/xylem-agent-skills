# Mission Ownership

## When to use

Own a compiler task through integration and verification, including cross-repository dependencies.

## Procedure

1. Map the requested outcome to observable acceptance criteria; identify the consumer, producer, and validation command before editing.
2. Turn resolvable handoffs into tasks; investigate failing prerequisites and continue independent work when genuinely blocked.
3. Track implemented, integrated, verified and externally blocked separately; avoid expanding a finite readiness mission into unlimited optimization.

## Exit evidence

A passing consumer-level check or precise external blocker with reproduction, owner and next action.

## Guardrails

Apply the repository rules and current mission authorization. Do not invent source facts, bypass security controls, or claim checks that were not run. If verification is unavailable, mark the result pending or blocked with the exact reason and continue independent in-scope work.
